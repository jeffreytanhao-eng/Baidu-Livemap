# 设施分类重构：8 类 → 7 类（六类拟案评估 + 实施计划）

## 一、评估结论（回应「先评估一下是不是合理」）

**总体合理，方向正确**，比现有 8 类更贴近「一刻钟便民生活圈」的官方口径，具体：

| 新类 | 评估 |
|---|---|
| 便利生活 | ✅ 最有价值。整合买菜/理发/洗衣/快餐/蛋糕，比「菜市场+日常购物」更贴近体感；设施密度高，`count≥3 且最近≤X` 规则天然适配（继承现 daily 规则） |
| 娱乐休闲 | ✅ 健身/游泳/洗浴/按摩并入后密度大幅提升（健身房遍布社区周边），不再天然稀疏；电影院/剧院仍保留。商业健身房从公共空间剔除后归入此类，社区健身园（公园性质）仍留公共空间 |
| 大型商超 | ✅ 检索词含「超市$家居」后，山姆/物美/京客隆/宜家/红星美凯龙等中大型购物场所均命中，密度有保障；纯购物中心仍稀疏但不再重罚 |
| 学习教育 | ✅ 幼儿园+中小学+大学合并合理（幼儿园密集，最近≤X 判定会被幼儿园满足，属合理口径）；大学是加分项 |
| 医疗保障 | ✅ 药店/诊所密集，最近≤X 判定稳定。**养老并入后，检索词必须保留养老院/养老驿站**，否则丢政策亮点 |
| 公共空间 | ✅ 上一轮已理顺（公园/绿地/景区核心化、剔政府机关与商业健身、含图书馆），直接沿用 |
| 交通出行 | ✅ 现方案完全缺失的维度，补上很对。**地铁一票制**（无地铁看公交、标注「公交」）已确认 |

**注意**：您写「六类」但实际列了 **7 组**（便利生活/娱乐休闲/大型商超/学习教育/医疗保障/公共空间/交通出行）。本方案按 **7 类**实施。

**实施中的关键处理**（不改变您的分类，只做工程适配）：
1. 「百度检索词」不加「度假村/温泉」以外的噪声词——实测「景区」「绿地」作检索词会返回旅行社/墓/清真寺等噪声，娱乐休闲用「电影院$剧院$体育馆$游泳馆$展览馆$洗浴$温泉$度假村」，名称分级逻辑沿用 public 的经验
2. 地铁站检索返回「站+出口」，需按 uid/名称+30m 去重后取「站」级最近值；公交站量大，cap 20 内取最近
3. 网格盲区（现「菜场/药店/小学」三键）随新锚点类改为「便利/医疗/教育」
4. 综合分从 4 部分改 5 部分（新增交通专项权重），等时圈面积权重 0.15→0.10

## 二、新分类契约

### 类别 id、检索词、达标规则

| id | 展示名 | 百度检索词（$=或） | 达标规则 |
|---|---|---|---|
| convenience | 便利生活 | 便利店$菜市场$农贸市场$理发店$快餐$蛋糕房$洗衣店 | count≥3 且最近≤X（继承 daily） |
| leisure | 娱乐休闲 | 电影院$剧院$体育馆$游泳馆$展览馆$健身$洗浴$按摩$温泉$度假村 | 最近≤X |
| mall | 大型商超 | 购物中心$商场$超市$奥特莱斯$家居（「超市」天然覆盖山姆/物美/京客隆/宜家等中型及仓储超市） | 最近≤X |
| education | 学习教育 | 幼儿园$小学$中学$大学 | 最近≤X |
| health | 医疗保障 | 医院$社区卫生服务中心$诊所$药店$养老院$养老驿站 | 最近≤X |
| public | 公共空间 | 公园$社区服务中心$图书馆（沿用） | 最近≤X（沿用现有名称过滤/核心度排序） |
| transport | 交通出行 | 地铁站 + 公交站（两次检索，标 metro/bus） | **一票制**：地铁站最近≤X → 达标（地铁）；否则公交站最近≤X → 达标（标注「公交」）；均无 → 缺口 |

### 综合分（5 部分，权重写入 scoring.py 常量，可调）

```
score = 0.40×coverage7        # 7 类达标比例（娱乐/商超各≈5.7%，符合「小权重」）
      + 0.20×anchor3          # 锚点三类的达标比例：convenience/health/education
      + 0.15×proximity        # 锚点三类平均最近步行分钟/X 线性衰减
      + 0.15×transport        # 交通专项：地铁达标 1.0 / 仅公交达标 0.6 / 均不达标 0
      + 0.10×area_ratio       # 等时圈面积/理想圆（0.15→0.10）
```

交通有效权重 = 0.15 + 0.40/7 ≈ **0.21，七类中最高**（满足「地铁站高权重」）。
锚点三类（便利/医疗/教育）各 ≈0.164；公共空间 ≈0.057；娱乐/商超各 ≈0.057。

### 前端雷达

7 轴（radarOption 本就按 categories 动态画轴，无需改公式）；标题「八类设施达标雷达」→「七类设施达标雷达」；transport 轴的近度分取**地铁最近分钟**（无地铁用公交分钟并在 tooltip 注记）。
