# Checklist

## 主引擎正确性（主创新，硬验收）

- [x] 等时斑沿路网走，不出现锯齿圆/外圈 24 边形（Story 2.10 硬单测通过）
- [x] 斑不穿过住宅楼外扩区、不穿过未架桥水面；过河必须经桥或人行地道
- [x] 斑可进入商场轮廓（青色），绕开相邻住宅（灰/暖色）；办公主体不可穿但底商廊道可走
- [x] 未知建筑默认不可穿越；不可进入多边形外扩 1.5 m 墙厚生效
- [x] 快速路/无步道主干作为阻隔线，斑在此断开；人行天桥处可续上
- [x] 一次 Dijkstra 产出全部时间分层，无按层多次全图搜索
- [x] 百度步行折线注入为 `source=baidu` 高权边，与百度 App 大体重合处可叠看；更保守处报告写明原因（住宅不可穿）

## 快速出圈性能

- [x] 图在服务启动时载入内存，请求期内无 GeoJSON 现场建图
- [x] 无缓存冷请求：300 ms 内出快拍圈层，1.5 s 内出精拍（劲松默认点实测）
- [x] 命中 `nodeId+minutes` 缓存：p95 <300 ms 出精拍
- [x] 主圈计算不调用 RouteMatrix；评委连续点图不触发每次 20+ 次 Web API；进度条仅显示「校准与设施检索」
- [x] 度 2 收缩与 25 m 吸附网格生效（邻点击中同一门口直接返回）

## X 分钟参数

- [x] 缺省 15；快捷 5/10/20；自定义 5–30 整数，非法值内联提示不请求
- [x] 改 X 或改中心不自动计算；黄点+水印提示「以下为上次结果」；点「开始体验」后圈/覆盖/报告全按 X 重算
- [x] 等时分层随 X（15→5/10/15；20→5/10/15/20）；直线对照圆半径随 X 缩放
- [x] 综合分分母为当前 X（minutes=10 与 20 单测达标不同）；代码无写死 15
- [x] `POST /api/v1/checkup` 对 minutes 越界返回 400；分享 URL 带 lat/lng/minutes 可回填

## 覆盖、盲区、扇区

- [x] 8 类 POI 检索半径 `max(1500, 90*X)`；去重/降权/cap 20 生效；圈内判定=步行耗时 ≤X
- [x] 1 km 三类盲区网格固定 1000 m 不随 X；增强开关才跟 X；单类/复合可筛；4-连通区域与带状走廊上图
